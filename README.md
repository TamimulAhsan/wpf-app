# Personal Expense Tracker

A WPF (C#) desktop app for recording and summarising expenses.

## Requirements
- Windows 10 / 11
- .NET 8 SDK (or Visual Studio 2022+ with the **.NET desktop development** workload)

## Open
1. Extract the ZIP file to a folder.
2. Open `PersonalExpenseTracker.sln` in Visual Studio.
3. Run the app on Windows with **F5** or `dotnet run`.

## Build
- In Visual Studio: **Build > Build Solution** (Ctrl+Shift+B).
- Or from a terminal in the project folder: `dotnet build`

## Run
- In Visual Studio: press **F5** (or click **Start**).
- Or from a terminal in the project folder: `dotnet run`
